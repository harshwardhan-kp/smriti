Make LiteRT-LM the primary on-device LLM engine, with MediaPipe as fallback. Edit files directly.

WHY (all measured on an iQOO 15, SM8850, Gemma 3n E4B, today)
  MediaPipe tasks-genai : generate 45-50 s, and it emits <end_of_turn> as literal text then
                          regenerates the whole answer ~10 times, burning most of that time.
  LiteRT-LM             : generate 16.4 s for the identical model on the identical CPU backend,
                          output clean, no <end_of_turn> spam - because it applies Gemma's chat
                          template. A 3x win.
MediaPipe's LLM Inference API is also officially maintenance-only.

   enableResponseFormat = true for it to take effect.
       val conv = engine.createConversation(ConversationConfig(enableResponseFormat = true))
       val reply = conv.sendMessage(
           Message(role = Role.USER, contents = Contents.of(Content.Text(prompt))),
           responseFormat = jsonSchema?.let { ResponseFormat.json(it) }

   close() must close the engine.
