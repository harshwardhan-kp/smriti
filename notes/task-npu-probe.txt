BEHAVIOUR
Log tag "SmritiNPU". For EACH backend in this order — NPU, GPU, CPU — attempt a full
load-and-generate and log the result, then move to the next:

  1. Backend.NPU(nativeLibraryDir = context.applicationInfo.nativeLibraryDir)
  2. Backend.GPU()
  3. Backend.CPU()

For each attempt:
  a. Log "ATTEMPT <name>" BEFORE constructing anything. THIS IS CRITICAL: a native backend can
     segfault and take the whole process down with it, exactly as MediaPipe's GPU path does on
     this device. If the attempt line is not written first, a crash leaves no evidence of which
     backend was being tried.
  b. val engine = Engine(EngineConfig(modelPath = <path from ModelProvisioner>, backend = <the backend>))
     engine.initialize()      // may take ~10 s; already on a background thread
  c. Time initialize() in ms and log "  init: <n> ms".
  d. val session = engine.createSession(SessionConfig())
     val out = session.generateContent(listOf(InputData.Text(PROMPT)))
     Time it, log "  generate: <n> ms".
  e. Log the FULL response, one logcat line per line of it:  out.lines().forEach { Log.i(TAG, "  $it") }
  f. Log "  RESULT <name>: OK" on success.
  g. Wrap the whole attempt in try/catch(Throwable) and log "  RESULT <name>: FAILED <class>: <message>"
     then CONTINUE to the next backend. One backend failing must not stop the others.
  h. Always close the session and the engine (both are AutoCloseable) in a finally block.
