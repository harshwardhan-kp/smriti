4. `app/src/main/java/com/smriti/app/ai/Extractor.kt`
   - `class Extractor(private val engine: LlmEngine)`
   - `suspend fun extract(ocrText: String, transcript: String): StructuredRecord`
   - Prompt: instruct the model that today's date is passed in, that it must answer with a single
     JSON object and nothing else, and give the exact schema
     `{"title":"","summary":"","people":[],"amounts":[{"value":0,"currency":"INR","label":""}],
       "tags":[],"actions":[{"text":"","due":"YYYY-MM-DD or null"}]}`.
     Include the OCR text and the transcript in clearly labelled sections, each truncated to
     1500 characters. Ask for a title of at most 8 words.
   - ROBUSTNESS, this is the important part. A 1B model will not reliably return clean JSON:
       a. take the substring from the first '{' to the LAST '}'
       b. strip markdown fences if present
       c. remove trailing commas before } or ] with a regex
       d. parse with Gson into the data classes
       e. on any exception, retry ONCE with a shortened prompt that omits the OCR text
       f. on second failure return `StructuredRecord.fallback(transcript.ifBlank { ocrText })`
     Never throw out of `extract`. Losing the user's capture because the model rambled is the
     worst possible failure.
   - `internal fun repairJson(raw: String): String` exposed for unit testing.
