3. CREATE app/src/offline/java/com/smriti/app/capture/SherpaWhisperAsr.kt

   Model it CLOSELY on the existing VoskAsr.kt in the same source set: same AudioRecorder use,

   sherpa-onnx API (verified by javap against the actual AAR — use exactly this):
       import com.k2fsa.sherpa.onnx.*
       val cfg = OfflineRecognizerConfig(
           featConfig = FeatureConfig(sampleRate = 16000, featureDim = 80),
           modelConfig = OfflineModelConfig(
               whisper = OfflineWhisperModelConfig(
                   encoder = <encoder path>,
                   decoder = <decoder path>,
                   language = "",          // "" = auto-detect language
                   task = "transcribe"
               ),
               tokens = <tokens path>,
               numThreads = 4,
               debug = false
           ),
           decodingMethod = "greedy_search"
       )
       val recognizer = OfflineRecognizer(config = cfg)   // assetManager defaults to null -> reads file paths
       val stream = recognizer.createStream()
       stream.acceptWaveform(samples, 16000)              // samples is FloatArray
       recognizer.decode(stream)
       val text = recognizer.getResult(stream).text
       stream.release()
   Use NAMED arguments everywhere — OfflineModelConfig has 25 constructor parameters and
   positional arguments will silently bind to the wrong slots.

   CRITICAL — WAV to FloatArray conversion:
   AudioRecorder.stop() returns a File: 16 kHz mono 16-bit PCM WAV with a 44-byte header.
   sherpa needs FloatArray normalised to [-1.0, 1.0]. So: skip the first 44 bytes, read the
   rest as LITTLE-ENDIAN signed 16-bit samples, and divide each by 32768.0f. Getting the
   endianness or the divisor wrong yields silence or noise, not an error — there is no way to
   detect it except by listening to the output, so be careful here.

   Cache the OfflineRecognizer statically (loading is slow, ~seconds) exactly as VoskAsr
   caches its Model. Never load it twice.
